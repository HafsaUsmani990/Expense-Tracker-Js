# Expense-Tracker-Js
Expense Tracker (JavaScript)

A simple and interactive Expense Tracker built using HTML, CSS, and JavaScript. It allows users to add, edit, delete, and track daily expenses with persistent data storage.

 ## Features

Add new expenses with name, amount, category, and date

Edit and delete existing expenses

Automatically calculates total expenses

Stores data using Local Storage (data persists after refresh)

Responsive design for different screen sizes

 ## Technologies Used

HTML
CSS
JavaScript (DOM manipulation, Local Storage)

## How It Works

User enters expense details and clicks Add Expense
Data is stored in an array and saved in localStorage
Expenses are displayed in a table dynamically
Total amount updates automatically
Edit/Delete buttons allow modifying existing entries
